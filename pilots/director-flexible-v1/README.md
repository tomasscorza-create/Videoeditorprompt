# Fixtures del contrato creativo flexible V1

Estos documentos pertenecen a V0. Validan intención, participantes, voz,
recetas y secuencias coordinadas, pero todavía no son consumidos por el runtime.

Casos válidos:

- `voiceover-prop.json`: cero personajes y narración fuera de campo;
- `solo-character.json`: un personaje en monólogo;
- `dialogue-coordinated.json`: dos personajes con una reacción articulada;
- `visual-with-guide.json`: narración, prop y personaje visual de apoyo.

Los casos inválidos congelan límites de modo, requisitos de receta, bindings y
capacidades declaradas por los recursos.
