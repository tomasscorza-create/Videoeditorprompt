# Comandos y Atajos de Teclado

Este documento lista todos los atajos de teclado y comandos de manipulación rápida integrados en la interfaz del Diseñador de Videos, pensados para acelerar el proceso de edición y previsualización.

## Visor y Reproducción

| Acción | Comando / Atajo | Descripción |
| :--- | :--- | :--- |
| **Reproducir / Pausar** | `Espaciador` | Alterna entre reproducir y pausar el video actual. |
| **Reproducir / Pausar (Mouse)** | `Clic izquierdo` | Hacer clic directamente sobre el video (canvas) pausa o reanuda la reproducción. |
| **Retroceder** | `Flecha Izquierda` | Retrocede el video 0.5 segundos. |
| **Avanzar** | `Flecha Derecha` | Avanza el video 0.5 segundos. |
| **Alternar Bucle (Loop)** | `L` | Activa o desactiva la repetición automática (loop) de la escena. |
| **Silenciar (Mute)** | `M` | Silencia o restaura el volumen del audio. |

## Interfaz General

| Acción | Comando / Atajo | Descripción |
| :--- | :--- | :--- |
| **Navegar Escenas** | `Rueda del Ratón` | Usar la rueda del ratón sobre la galería permite hacer scroll horizontal rápidamente. |

*(Este archivo se mantendrá actualizado a medida que se integren nuevos comandos a la herramienta).*
