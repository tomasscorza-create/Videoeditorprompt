ejecuta fuera del árbol del proyecto.

| Qwen3-8B | Planificación semántica local | Apache-2.0 | https://huggingface.co/Qwen/Qwen3-8B |

La licencia del repositorio open source de Ollama no debe interpretarse automáticamente
como licencia de cualquier aplicación gráfica o instalador distribuido por terceros.
Antes de redistribuir binarios, instaladores o pesos se deben revisar los términos del
artefacto exacto. La aplicación actual solo se conecta a una instalación local existente.

El repositorio aún no tiene una licencia general. Elegirla requiere una decisión explícita
del propietario antes de compartir, publicar o comercializar el código.
